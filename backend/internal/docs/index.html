建筑工程项目成本管控 API 服务

Go 1.22 + Gin + GORM + PostgreSQL 15 + Redis 7 · /docs/openapi.json

认证

POST/api/v1/auth/loginJWT 登录（admin/admin123、finance/finance123、accountant/accountant123）

项目预算 ProjectBudget

GET/api/v1/budgets?projectId=预算列表
POST/api/v1/budgets编制预算
GET/api/v1/budgets/:id预算详情
PUT/api/v1/budgets/:id编辑草稿预算
POST/api/v1/budgets/:id/submit提交审批
POST/api/v1/budgets/:id/approve / /reject审批通过/驳回（FinanceManager/Admin）

成本项 CostItem

GET/api/v1/cost-items?budgetId=成本列表
POST/api/v1/cost-items录入成本（Accountant 等，自动计算差异）
GET/api/v1/cost-items/:id成本详情
PUT/api/v1/cost-items/:id核对成本
POST/api/v1/cost-items/:id/mark-abnormal标记异常

变更单 ChangeOrder

GET/api/v1/change-orders?projectId=变更单列表
POST/api/v1/change-orders发起变更（自动计算变更后金额）
GET/api/v1/change-orders/:id变更单详情
POST/api/v1/change-orders/:id/submit / /approve / /reject / /cancel审批流

成本分析报告 CostReport

GET/api/v1/reports?projectId=报表列表
POST/api/v1/reports/generate生成报表（结果 Redis 缓存 10 分钟）
GET/api/v1/reports/:id读取报表（优先缓存）

其它

GET/api/v1/audit-logs审计日志
GET/healthz健康检查
